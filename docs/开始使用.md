# 你的本地博客已经可以使用

正式目录是 `D:\博客正式版\my-blog`，在线地址是 <https://yintaoc3-collab.github.io/my-blog/>，仓库是 <https://github.com/yintaoc3-collab/my-blog>。以后只在正式目录里改内容，先前的目录保留作旧版参考。

博客界面与四个栏目已经做好，真实文章暂时为空。页面上的“待收录”属于正常状态。

## 第 1 步：打开博客文件夹

1. 打开 Windows 文件资源管理器。
2. 在地址栏输入 `D:\博客正式版\my-blog`，按回车。
3. 确认能看到 `hugo.yaml`、`content`、`docs` 和几个 `.cmd` 文件。
4. 在 VS Code 中选择“文件 → 打开文件夹”，打开这个 `my-blog` 文件夹。

目的：让预览、图片、文章和 Git 都使用同一份正式源码。

## 第 2 步：预览界面

1. 双击 `start-blog.cmd`。`start-ui-preview.cmd` 也可以，两个按钮使用同一个启动流程。
2. 等待窗口显示启动网址，浏览器会自动打开。
3. 默认网址为 <http://127.0.0.1:1321/>。如果端口已占用，脚本自动换端口，请使用窗口显示的网址。
4. 如果这份目录的预览已经在运行，脚本会直接打开已有预览。
5. 查看首页、四个栏目、关于我和搜索；点击月亮或太阳按钮检查明暗主题。
6. 按 `Ctrl+C`，或双击 `stop-blog.cmd`，可以停止正式版预览。

目的：在自己的电脑上查看修改效果。编辑文件并保存后，Hugo 会自动刷新页面。预览地址只供本机访问。

## 第 3 步：写第一篇作品

1. 在 `docs\templates` 找到 `作品文章.md`，先打开看看各部分怎么填写。
2. 在 `content\projects` 新建一个英文目录，例如 `stm32-oled`。
3. 把作品模板复制到新目录，把复制后的文件改名为 `index.md`。
4. 用 VS Code 打开 `index.md`，填写标题、日期、介绍和正文。日期请写实际写作日期。
5. 先保留 `draft: true`，这样可以在本地预览，正式网站不会发布。
6. 把作品照片放在同一个目录，例如 `board.jpg`；在正文写 `![开发板实物](board.jpg)`。
7. 保存文件，查看预览里的作品页面。
8. 整理好之后，再把 `draft: true` 改成 `draft: false`。日期不要晚于今天，否则默认正式构建暂时不会显示文章。

目的：把真实作品记录成可长期保存的 Markdown 文件。其他三类内容使用 `docs\templates` 中对应模板，分别放进 `opensource`、`notes`、`goodies` 栏目。

## 第 4 步：检查正式版本

1. 双击 `build-blog.cmd`。
2. 等待出现 `Build succeeded`。
3. 正式网页生成在 `public`，该目录会先清除旧输出。
4. 如有报错，先看文件名和行号，再检查 YAML 缩进、图片名和 Markdown。

目的：确认网站可以正式发布。这一步只构建本地网页，不会上传；`draft: true` 的草稿不会进入正式网页。

## 第 5 步：备份

1. 双击 `backup-blog.cmd`。
2. 在 `.backups` 找到新的 `blog-source-日期时间.zip`。
3. 再把这份 ZIP 复制到另一个磁盘或可靠的备份位置。

目的：保留文章、图片、主题、脚本、教程和部署配置。源码备份不包含 Hugo 程序与 Git 历史；包含便携 Hugo 的完整基础包可用于换电脑。两种包遇到同名文件都不会覆盖。

## 第 6 步：更新在线博客

1. 在 VS Code 左侧打开“源代码管理”。
2. 检查修改列表，只提交你准备保存或公开的内容。
3. 暂存修改，填写提交说明，例如“新增 STM32 OLED 作品”，然后提交。
4. 点击推送或同步到已有远端 `https://github.com/yintaoc3-collab/my-blog.git`。
5. 在仓库顶部的 Actions 查看 `Build and deploy blog`，等 `build` 和 `deploy` 都变绿。
6. 打开 <https://yintaoc3-collab.github.io/my-blog/> 检查文章和图片。

目的：把本地修改保存到 GitHub，并自动更新网站。仓库已经存在，后续使用提交和推送即可。

注意：即使文章是草稿，推送到公开仓库后，其 Markdown 源文件仍然公开。只把适合公开的资料放进这个仓库。

## 常见情况

| 现象 | 怎么处理 |
| --- | --- |
| 首页没有文章 | 当前还没有真实文章；完成第 3 步后就会出现 |
| 本地能看到文章，网上没有 | 检查 `draft`、日期、是否已经推送，以及 Actions 是否成功 |
| 预览端口换了 | 使用启动窗口显示的网址，脚本会自动选择空闲端口 |
| 想结束预览 | 按 `Ctrl+C` 或双击 `stop-blog.cmd` |
| 图片打不开 | 图片和 `index.md` 放在同一目录，图片文件名与正文引用保持一致 |
| 关于我还不完整 | 编辑 `content/about.md`，填入你准备公开的真实介绍 |
